# Space Shooter

A space-shooter game project built with Godot. The project explores game scenes, player movement, shooting, enemies, and game assets as a hands-on game-development learning project.

## Tech and tools
- Godot Engine 4.6
- C# / .NET project configuration
- Godot scenes, scripts, and imported game assets

## Controls
| Action | Input |
|---|---|
| Move left | A |
| Move right | D |
| Move forward | W |
| Move backward | S |
| Shoot | Space or left mouse button |

## Run the game
1. Install Godot 4.6 with .NET support.
2. Clone this repository.
3. Open the project folder in Godot using `project.godot`.
4. Allow Godot to import the project assets.
5. Run the configured main scene from the editor.

## Repository contents
- `Scenes/` — game scenes
- `global/` — shared game logic
- Game scripts and visual/audio assets
